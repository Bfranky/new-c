# Beauté by Zee (`beautebyzee_`) — Next.js Web App

A modern, high-performance, responsive web application for **Beauté by Zee** (Makeup Artist in Eyita, Ikorodu, Lagos).

Designed with strict adherence to **restrained editorial aesthetics** (only 2–3 core colors: Obsidian Noir `#151311`, Warm Linen Silk `#FAF8F5`, and Champagne Bronze `#B88947`), **seamless navigation**, and an **exceptional human experience**.

---

## 🌟 Key Features

1. **Human-First WhatsApp Booking Engine**:
   - Clients choose their service (Bridal, Owambe, Soft Glam, Gele Tying), location (Studio in Eyita vs Home Service), preferred date, and time slot.
   - Automatically compiles a structured, polite WhatsApp booking inquiry sent with 1 tap directly to **0813 894 8285** (`wa.me/2348138948285`).
   - Zero friction: No forced account creation, no password resets, no lost inquiries.

2. **Google Business Profile Integration**:
   - Showcases the business's **5.0 ★ Rating** from 11 Google reviews.
   - Real featured reviews with owner responses:
     - **Vibes Angel**: *"The makeup was super good, blend with my skin and last for the day"*
     - **Dewunmi Arike**: *"Own one zee of Lagos ❤️💃she is the best🔥🤍 …"*
     - **Gift Anyanwu**
   - Direct button to "Write a Google Review" and view live maps location.

3. **Studio Location & Directions**:
   - Address: `24 Oguntuga Street, Eyita, Ikorodu 104101, Lagos`
   - Plus Code: `JGH2+XW Ikorodu`
   - Real-time opening status indicator (Mon-Sat 8:00 AM – 7:00 PM West Africa Time).
   - 1-click **Get Directions in Google Maps** & **Copy Address** buttons.
   - Interactive popular times visualization (highlighting peak hours from 6 AM to 9 PM).

4. **Curated Portfolio Lookbook**:
   - Filterable categories: Bridal, Owambe, Soft Everyday Glam, and Gele Styling.
   - Fullscreen detail view with an instant *"Request This Exact Look on WhatsApp"* button.

5. **Local Business SEO & Schema.org**:
   - Embedded `BeautySalon` structured JSON-LD with geo-coordinates, address in Eyita Ikorodu, telephone, hours, and 5.0 rating for Google local search ranking.

## 🚀 Getting Started

To run the development server locally:

```bash
npm run dev
# or
npm.cmd run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Production Build

```bash
npm run build
npm start
```
